# EDS_1330_Matta

## Project Title
Grid Frequency Volatility Analysis — GRD-03

## Description
A Python-based data analytics pipeline analyzing grid frequency volatility 
using smart grid monitoring data. Built for Computer Programming 1 Final Project.

## How to Run
1. Install dependencies: `py -m pip install -r requirements.txt`
2. Run the pipeline: `py main.py`

## Libraries Used
- numpy, pandas, matplotlib, plotly, scipy
